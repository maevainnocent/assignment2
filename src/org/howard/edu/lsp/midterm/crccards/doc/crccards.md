# CRC Card Explanation

Library collaborates with Book because Library's responsibilities, maintaining books, finding them, and coordinating borrowing and returning, require it to hold and operate on Book objects. Book does not collaborate with Library because its responsibilities (storing book information, maintaining availability, and validating borrow and return) are self-contained and need no knowledge of any collection, so the dependency runs in one direction only and Book stays reusable on its own. Library enforces the three-book borrowing limit because the limit is a rule about the whole collection, and only Library can see all books at once. A single Book knows only its own state, so it cannot know how many other books are borrowed. This split follows the CRC cards: Book validates its own state changes, and Library coordinates and enforces cross-book business rules.
